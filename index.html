🔄 Mode d'accès aux données

Choisissez comment les données sont stockées et accédées. Local fonctionne hors ligne. Cloud synchronise via Firebase / Firestore.

Mode actuel : —

🔐 Espace technique Firebase

Verrouillé

La configuration Firebase et les informations d’authentification sont masquées. Saisissez votre mot de passe administrateur pour y accéder. L’accès se referme automatiquement après 5 minutes.

⚠️ Ne partagez jamais ces informations. Ne les copiez pas dans un message ou un document.
Mise en place Firebase
  1. Créez un projet dans Firebase Console.
  2. Activez Firestore Database et Authentication par e-mail/mot de passe.
  3. Ajoutez une application Web et collez la configuration JSON ci-dessus.
  4. Les collections attendues sont produits, mouvements, ventes, commandes, fournisseurs, utilisateurs, clients, depenses et retours.
  5. Configurez des règles Firestore strictes avant la production.
Authentification
  • Fournisseur « E-mail/Mot de passe » activé dans Firebase Authentication.
  • Un seul compte administrateur au départ ; les autres comptes se créent depuis Utilisateurs.
  • Ne désactivez pas l’inscription publique : la gestion des comptes en dépend.
